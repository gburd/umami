# Umami Release Implementation Plan

**Goal:** Fix the fourteen reviewed defects, independently review the fixes, and qualify release 0.2.0.

**Architecture:** Preserve exact signatures and the public detector entry points.  Isolate CLI input,
state ownership, and timestamp policy from the detector's statistical learning.

**Tech Stack:** Rust workspace; standard-library statistics; CLI-only parsing and OS dependencies.

**Spec:** docs/superpowers/specs/2026-11-15-release-design.md (approved).

## Global constraints

Preserve the user's dirty main checkout.  Work under /scratch/umami.  Keep library MSRV 1.74 and
CLI MSRV 1.85, unless qualification demonstrates an unavoidable dependency conflict.  Package
umami-log retains lib name umami; umami-cli retains executable umami.  Use version 0.2.0.
Never activate Codeberg Actions.  Only chorus may provide EC2 qualification resources.
Run failing regressions before behavioral fixes; use existing test infrastructure.

## Review focus

- Timestamp rollover versus late historical input: never advance state on rejected future input.
- SIGTERM with idle stdin or blocked stdout: preserve accepted learning without hanging.
- Concurrent state writers and malformed state: fail without replacing another writer's data.
- Restart inside a minute or cooldown: retain the count and suppress duplicate alerts.
- Extracted package: no tests or documentation depend on workspace-external files.

## Task 1: Detector (findings 4, 5, 6, 14)

Files: umami/src/detector.rs, umami/src/profile.rs, and adjacent unit tests.
Keep observe(), observe_tokens(), sweep(), and store() entry points.  Add serde-default private
rate and cooldown state.  Add an Anomaly field identifying changed parameter slot ordinals.

- [ ] Add failing tests for jittered heartbeat, irregular baseline followed by same-second flood,
  skipped minutes, late events, timestamp/ID parameter noise, and disabled tracking.
- [ ] Implement completed-minute statistics with thirty-minute warmup; floor variance at
  max(variance, mean, 1).  Aggregate skipped zero buckets without per-minute loops.
- [ ] Learn nonnegative return gaps; require twenty intervals and coefficient of variation <=0.2
  for stops.  Saturate arithmetic at i64 boundaries.
- [ ] Add independent rolling 86400-second stop/spike cooldowns per profile, persisted through
  restart.  Continuous silence remains one episode, not a daily reminder.
- [ ] Track parameters only when enabled, excluding Timestamp after assigning slot ordinals.
  Require twenty preceding observations and distinct values <= one tenth of observations.
- [ ] Test stable parameter changes and serialization of partial minutes and cooldowns.
- [ ] Run cargo fmt --check, clippy warnings-as-errors, build, and workspace tests; commit paths.

## Task 2: CLI and time (findings 2, 7, 8, 9)

Files: umami/src/time.rs, umami-cli/src/commands/detect.rs and new focused input/state modules,
umami-cli/Cargo.toml, and umami-cli/tests/cli.rs.  Coordinate Anomaly's new slot field at integration.

- [ ] Add failing CLI regressions for multi-day syslog gaps, New Year, future poisoning, signals,
  concurrent state writers, malformed state, multiline input, and explicit timestamp format.
- [ ] Preserve initial historical inference; introduce explicit continuing-year context.  Track
  tagged systems independently.  Reject times beyond wall time plus one day before observing.
- [ ] Own state with a lifetime advisory lock; use unique same-directory atomic saves.  Strictly
  validate envelope version, clock mode, tokenizer, and preprocessing settings.  Bump format to 2
  and refuse version 1 without overwriting it because tokenizer hashes change.
- [ ] Use bounded byte input and timed wakeups, not unbounded queued lines.  Save on SIGINT/SIGTERM
  and checkpoint dirty state every sixty monotonic seconds.  Test stdout backpressure separately.
- [ ] Add opt-in --multiline indentation assembly, 1 MiB event limit and one-second idle flush.
  Reject --tagged plus --multiline initially; preserve orphan content.  Parse only first-line time.
- [ ] Add --time-format with standard strftime parsing, explicit year, timezone support, strict
  mismatch diagnostics, and normalization of the consumed prefix into a Timestamp token.
- [ ] Run fmt, clippy, build, and tests; record any blocked-output limitation accurately; commit.
